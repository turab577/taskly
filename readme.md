Installation : 

After installing repository , run 'npm install' in the terminal . 

Running application on android : 

Run 'npx expo start' or yarn start in the terminal . You will see a QR code and an IP . 
Now , install expo go app from the playstore . Once it is installed , open it . It will show two options one to scan QR code and other to enter the URL manually . Once you scan the QR code or enter the url manually , the app will start running automatically . 

To reload the app , press 'r' in the terminal where the expo is running . You can also see the project logs in the terminal .
